Biotron beta diagnostics

This beta sends limited technical events while the page is online. They help Playtronica see whether connecting, calibration, sound or saved settings stopped working in a specific build. Sending diagnostics never changes the device and does not affect offline play.

Events contain a random ID for this browser session, the exact web build, broad browser and operating-system families, Web MIDI availability, the number of matching ports, operation states and fixed error codes. Firmware version is included only when Biotron reports it. If you answer the first-sound question, your choice is recorded separately from whether the audio engine was running.

Events do not contain your name, email, MIDI port name or ID, device serial number, raw MIDI or SysEx bytes, audio, preset values, full browser user agent or your WhatsApp message. Your session ID changes when the page is reopened. The technical event database is in Cloudflare's EU jurisdiction. Cloudflare handles the network request and may process connection metadata under its own service terms.

We use these events to diagnose beta failures and compare exact builds. The planned retention for individual events is 90 days. To ask about diagnostic data, write to manirko@playtronica.com.
